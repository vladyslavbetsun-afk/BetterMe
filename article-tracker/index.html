Adding an article to the tracker

The list comes from Jira project BP, so there is nothing to edit here.

  1. New articles and updates join automatically when their BP ticket moves to Published and the publisher posts the live betterme.world/articles link as a comment.
  2. To track any other article, add the label perf-track to its BP ticket. The ticket needs a comment that holds only the live link. It shows up the next time this page loads.
  3. To stop tracking a labelled article, remove the label.

    Where these numbers come from

    The article list is read live from Jira. Traffic, keywords and positions are Ahrefs Site Explorer estimates for the whole world, not Google Search Console clicks: the Search Console data connected to the Ahrefs Betterme project stops on Aug 3, 2026. Once Search Console syncs again, real clicks and impressions can be added here. Each page load uses roughly 26 Ahrefs API units per ranking article.
